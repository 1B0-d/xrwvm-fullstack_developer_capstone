# fullstack_developer_capstone

Best Cars dealership application developed as the IBM Full Stack capstone. The project combines Django, React, and an Express/MongoDB backend.

## Development

Install the Python requirements in `server/requirements.txt`, run Django migrations, and build the React application from `server/frontend`. The backend service and sentiment analysis endpoint require configuration in the lab environment. This is an educational application, not a production deployment.

## Dealership capstone package

The prepared dealership system, English documentation, technical report and verification evidence are in [project package](dealership-capstone/).
